# Hi, I'm Rob!

I'm currently an R&D engineer at Miele's Emerging Technologies Lab in Boston. My work spans electronics, software, and applied AI.

This is my personal page where I pursue passion projects and try to learn new things!

## Favorite Projects

Here are some of my favorite projects I have worked on/am working on:

- **[Anchor Link Display Text](https://github.com/rca-umb/anchor-link-display-text)**: Obsidian plugin, 4,000+ downloads. Check out the [scorecard](https://community.obsidian.md/plugins/anchor-display-text#scorecard).
- **[Open Duck Mini](https://github.com/rca-umb/Open_Duck_Mini_Runtime)**: Custom version of [Open Duck Mini](https://github.com/apirrone/Open_Duck_Mini_Runtime), a 14-servo bipedal robot. I got the original RL walking policy to run on a Raspberry Pi Zero W by rewriting the ONNX model and inference code in NumPy. My goal here is to customize this further to take an open-source design and turn it into something uniquely my own.
